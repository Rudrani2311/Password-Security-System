How k-Anonymity Works (Teacher Explanation):

1

Local SHA-1 Hashing

Your password is encrypted into a 40-character SHA-1 hash locally in the browser.

2

5-Character Prefix

Only the first 5 characters are sent to the HIBP API. Your full password never leaves the browser.

3

Local Suffix Match

The API returns matching suffixes. The browser compares your hash locally, preserving zero-knowledge privacy.

Architecture & Teacher Presentation Guide

Comprehensive overview of how the extension enforces 30-day rotation on external sites like Coursera.

1. The Problem Solved

Major websites like Coursera, GitHub, or LinkedIn do not allow external students or third-party apps to change their server-side database code. PassRotate acts as a Zero-Trust Client-Side Security Gateway in the browser that manages and enforces credentials on top of any target domain.

2. 30-Day Expiry & 5-Day Warning Flow

  • Day 0 - 24 (Active): User logs in normally. The badge on the extension icon shows green check.
  • Day 25 - 29 (Near Expiry): The extension injects an amber alert banner at the top of the website and sends a notification to the user's Gmail.
  • Day 30+ (Expired): The extension activates the Lockout Gatekeeper, blocking login form submissions on the website.

3. Option 1: Forgot Password & Gmail Reset

When expired, the user clicks "Reset via {Website} Forgot Password". The extension directs the user to the website's password reset endpoint. The website emails a reset link to the user's Gmail. Once the new password is set, the extension verifies it against the HaveIBeenPwned database and resets the 30-day lifecycle timer.
