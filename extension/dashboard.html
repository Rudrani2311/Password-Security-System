Breach Checker

Check if a password has been exposed in known data breaches using the HaveIBeenPwned API. Your password is never sent over the network — only the first 5 characters of its SHA-1 hash are used (k-Anonymity model).

How It Works

  1. The password is hashed locally using SHA-1.
  2. Only the first 5 hex characters are sent to HIBP's API.
  3. HIBP returns all hashes with that prefix — matching is done locally.
  4. Your full password never leaves your device.
